========================================================================
  SigeDash - REQUISITOS E LIBERACOES NO SERVIDOR DO CLIENTE
  (principalmente Windows Server - leia antes de instalar)
========================================================================

A maioria dos problemas de instalacao em Windows Server cai nestes pontos.
Garanta tudo abaixo ANTES de rodar o instalador.

1) EXECUTAR COMO ADMINISTRADOR
   - O instalador (SigeDash-Installer.exe) e os scripts precisam de admin.
   - Clique direito -> "Executar como administrador".

2) EXECUTION POLICY DO POWERSHELL
   - O instalador ja roda os scripts com -ExecutionPolicy Bypass.
   - Se for rodar um .ps1 na mao:
       powershell -ExecutionPolicy Bypass -File .\instalar-tudo.ps1
   - Se houver GPO de dominio forcando a policy (escopo MachinePolicy),
     o Bypass e ignorado -> ajuste a GPO ou rode a partir do .exe.

3) SAIDA DE INTERNET (OUTBOUND) - liberar no firewall/proxy:
   - github.com e objects.githubusercontent.com  (cloudflared + releases)
   - get.enterprisedb.com                         (instalador do PostgreSQL)
   - api.cloudflare.com                           (criacao do tunnel/DNS)
   - *.cfargotunnel.com e o tunnel do Cloudflare  (443 TCP e 7844 TCP/UDP;
     se o 7844 estiver bloqueado o cloudflared cai para 443 automaticamente)
   NAO e preciso abrir portas de ENTRADA: o acesso externo e pelo tunnel
   (saida), e o backend/PostgreSQL ficam apenas em localhost.

4) TLS 1.2
   - Os scripts ja forcam TLS 1.2/1.3. Em Server MUITO antigo (2012R2/2016),
     se os downloads falharem com "Could not create SSL/TLS secure channel",
     habilite o TLS 1.2 no sistema (Easy Fix da Microsoft / registro .NET
     SchUseStrongCrypto) e tente de novo.

5) .NET FRAMEWORK 4.8  (necessario para o AGENTE)
   - O backend e self-contained (NAO precisa de runtime .NET).
   - O agente e .NET Framework 4.8. Server 2019/2022 ja tem; 2016/2012R2
     pode faltar. Sem 4.8 o servico SigeDashAgente nao inicia (sem dados).
   - Download: https://dotnet.microsoft.com/download/dotnet-framework/net48

6) VISUAL C++ REDISTRIBUTABLE x64
   - Necessario para o PostgreSQL inicializar. O instalador do PostgreSQL
     ja instala (--install_runtimes 1). Se faltar, instale o vc_redist.x64.

7) PORTAS LOCAIS LIVRES
   - 5000/TCP (backend, so localhost) e 5432/TCP (PostgreSQL, so localhost).
   - Se algo ja usa essas portas, libere antes de instalar.

8) FIREBIRD DO SIGECOM
   - Acessivel em localhost:3050 e o caminho do .FDB correto
     (padrao C:\SIGECOM\SIGECOM.FDB; se for outro, informe no instalador).

9) ANTIVIRUS / APPLOCKER
   - Libere as pastas C:\SigeDash e C:\Program Files\SistemasBr\SigeDash e
     os servicos SigeDashBackend, SigeDashAgente e cloudflared.

========================================================================
  SE DER PROBLEMA
========================================================================
  - Rode o diagnostico (aponta a causa de cada item):
        powershell -ExecutionPolicy Bypass -File .\diagnostico.ps1
  - Para recomecar do zero:
        powershell -ExecutionPolicy Bypass -File .\desinstalar-tudo.ps1
    e rode o instalador de novo (a mesma URL do tunnel e reaproveitada).
  - IMPORTANTE: entregue ao cliente a URL EXATA que o instalador mostra no
    final, com ".sigedash.com.br" (nao esqueca o ".br").
========================================================================
